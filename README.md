# 生活記録

睡眠、食事、睡眠周辺の生活イベント、顔写真、変動費を1日単位で残し、あとから関係を振り返るための自分用Webアプリです。健康状態の採点や生活の矯正は行いません。

公開URL：<https://kirokubox.github.io/life-record-app/>

## 開発

```powershell
npm.cmd install
npm.cmd run dev
npm.cmd test
npm.cmd run build
```

保存先はブラウザ内のIndexedDB（`life-record-app`）です。ログイン、バックエンド、クラウド同期はありません。通常JSONには画像本体を含めず、写真を守る場合は「写真を含む完全ZIP保存」を使います。

## 季節日記から移行する

1. 季節日記の設定画面で「通常JSON保存」を実行します。
2. 生活記録の「設定」→「季節日記から移行」で、そのJSONを選びます。
3. 新規追加、既存日への補完、競合などの件数を確認します。
4. 問題なければ「この内容で移行」を押します。

移行対象は睡眠（起床・就寝・仮眠・旧睡眠時間）と家計（日常費・満足費・反省費）です。日記本文、写真、気分、タグ、らくがきは移しません。既存日は空欄だけ補完し、異なる値を上書きしません。

## 初期版の範囲

- 睡眠・仮眠と7日平均
- 朝食・昼食・夕食・間食の時刻、短いメモ、写真
- 入浴・最終喫煙と就寝までの自動計算
- 1日1枚の顔写真
- 変動費全額、日常費、満足費、反省費
- 最近の記録・食事写真・顔写真・今期変動費
- 自動保存、PWAオフライン基盤
- JSONバックアップと写真つき完全ZIP
- 季節日記の通常JSONから、睡眠・仮眠・変動費だけをプレビューして追加移行

現在のアプリアイコンはPWA・公開確認用の仮アイコンです。正式アイコンのデザインは、日常試用とは分けて別工程で決定します。

季節日記本体の削除・変更、写真や日記本文の移行、Googleカレンダー連携、体調評価、栄養計算、AI診断は初期版に含めません。
